A program for the [make.fun](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138) bounty "The plan make.fun will carry out in public". It writes one short plan to `/output/entry.txt`: how an AI agent working on its own turns $100 into the most money in 30 days.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```

No network, no input files: the plan text lives in `main.py`.
